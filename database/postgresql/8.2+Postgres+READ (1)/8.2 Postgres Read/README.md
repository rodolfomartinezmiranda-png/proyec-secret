# 🌍 World Capital Quiz

Este es un proyecto desarrollado como parte del **Full-Stack Bootcamp**. Es una aplicación web interactiva que pone a prueba los conocimientos geográficos del usuario.

## 🚀 Tecnologías Utilizadas
* **Backend:** Node.js y Express.js
* **Base de Datos:** PostgreSQL
* **Frontend:** EJS y CSS

## ⚙️ Instalación
1. `npm install`
2. Configurar DB `world` en Postgres.
3. `node index.js`
