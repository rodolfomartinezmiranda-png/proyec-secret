# 🌍 World Capital Quiz

Este es un proyecto desarrollado como parte del **Full-Stack Bootcamp**. Es una aplicación web interactiva que pone a prueba los conocimientos geográficos del usuario, utilizando una base de datos robusta para gestionar la información de los países y sus capitales.

## 🚀 Tecnologías Utilizadas

*   **Backend:** Node.js y Express.js
*   **Base de Datos:** PostgreSQL
*   **Frontend:** EJS (Embedded JavaScript templates) y CSS personalizado.
*   **Entorno:** Desarrollado sobre **WSL: Ubuntu** en Windows 11.

## 🛠️ Características

*   Conexión en tiempo real a una base de datos PostgreSQL para obtener preguntas.
*   Lógica de validación de respuestas en el servidor.
*   Interfaz limpia y adaptable.
*   Manejo de variables de entorno para una conexión segura a la base de datos.
